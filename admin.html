Manual do Sistema

Bem-vindo ao Ponto Digital

Este sistema foi desenvolvido para facilitar o controle de jornada de trabalho através de reconhecimento facial. Abaixo você encontra um guia rápido de cada funcionalidade.

Dashboard (Visão Geral)

Acompanhe em tempo real:

  • Total de funcionários cadastrados.
  • Quantidade de registros realizados no dia.
  • Gráficos de frequência semanal e pontualidade.
  • Lista de funcionários ausentes com opção de enviar lembrete por e-mail.

Gerenciar Funcionários

Nesta tela você pode:

  • Cadastrar: Adicione novos colaboradores com foto para o reconhecimento facial.
  • Editar/Excluir: Atualize dados ou remova funcionários.
  • Perfil: Clique no nome para ver o histórico individual e o relatório de banco de horas.
  • Relatórios: Gere relatórios de ponto individuais.

Histórico de Pontos

Controle total dos registros:

  • Filtros: Busque por data específica.
  • Edição: Corrija horários ou adicione observações em caso de erros.
  • Exportação: Baixe os dados em CSV, Excel ou PDF para contabilidade.

Configurações

Personalize o sistema:

  • Aparência: Ative o Modo Escuro.
  • Regras: Defina o horário limite para considerar atrasos.
  • Jornada: Defina a jornada de trabalho para o cálculo do banco de horas.
  • Segurança: Altere a senha de administrador.
  • E-mail: Configure o servidor SMTP para envio de lembretes.
